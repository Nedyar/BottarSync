# Changelog

## 0.1.0 - First version

- **Every guild member's characters**, shared through hidden addon messages: name, realm, level, class, race, sex, faction, item level and equipped items, professions with their recipes, and talents (both specs).
- **A file for the Bot'tar bot**: at logout or `/reload`, everything is written as JSON into the saved variables file, together with the whole guild roster (rank, note, level, last time online), including members without the addon.
- `/bottar show [name]` shows a member's data as the bot gets it; `/bottar save` writes the file now.
- Translated into every client language.
